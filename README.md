# shaeekul-ameen.github.io

Personal academic and research website for **Shaeekul Ameen**.

## Site structure

- `index.html` — single-page portfolio website
- `assets/style.css` — responsive visual design
- `assets/script.js` — navigation, theme toggle, and reveal interactions
- `assets/images/` — profile and favicon assets
- `assets/cv/` — downloadable CV
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow

## Deploy

Push the contents of this repository to the `main` branch. The included GitHub Actions workflow deploys the site automatically to GitHub Pages.

If GitHub Pages is not already configured for Actions, open **Settings → Pages** and set **Source** to **GitHub Actions**.
